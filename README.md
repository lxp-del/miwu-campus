# 觅物小程序

基于 Java 和 Spring Boot 开发的校园二手交易平台，主要面向高校学生提供二手商品发布、商品浏览、在线沟通、订单管理、校园社区以及 AI 辅助服务等功能。

项目在传统二手交易业务的基础上，引入 LangChain4j、DeepSeek、Qwen-VL-Max 等 AI 能力，用于商品图片分析、商品描述生成、智能查询和业务知识问答。

# 功能介绍

## 1. 用户认证

平台针对校园用户设计了用户认证功能。

用户注册和登录后，由 Sa-Token 管理用户登录状态，并根据当前用户身份进行接口权限校验。

主要涉及：

* 用户注册
* 用户登录
* 用户身份认证
* 登录状态管理
* 用户信息维护
* 接口权限控制

对于商品、订单、评论和个人信息等接口，在执行具体业务操作前会对当前用户身份进行校验，避免用户操作其他用户的数据。

## 2. 商品管理

商品模块是平台的主要业务模块，负责二手商品的发布和管理。

用户可以填写商品标题、商品描述、商品价格、商品分类等信息，同时上传商品图片。

商品图片通过阿里云 OSS 进行存储，后端保存对应的 OSS 地址，并与商品业务数据建立关联。

主要功能包括：

* 商品发布
* 商品编辑
* 商品上下架
* 商品撤回
* 商品列表
* 商品搜索
* 商品详情
* 商品评论
* 商品状态管理

商品列表主要展示商品的基本信息，进入商品详情后可以查看完整描述、图片、价格及评论等内容。

## 3. 订单管理

平台针对商品购买过程设计了订单业务。

用户选择商品后可以创建订单，系统保存商品、买家、卖家、价格等相关信息，并根据业务状态进行订单管理。

订单相关功能包括：

* 创建订单
* 查询订单
* 查看订单详情
* 订单状态管理
* 个人订单管理

涉及商品和订单等多个业务数据修改时，通过 Spring 事务机制保证数据的一致性。

## 4. 实时私信

平台使用 WebSocket 实现买卖双方的实时私信。

用户建立 WebSocket 连接后，服务端记录用户与连接之间的关系，并根据接收用户进行消息路由。

主要处理：

* WebSocket 连接建立
* 用户身份绑定
* 用户连接管理
* 消息接收
* 指定用户消息发送
* 实时消息推送

用户发布商品后，可以直接通过私信与卖家进行沟通，不需要反复刷新页面获取新消息。

## 5. 校园社区

平台提供校园社区功能，用户可以发布帖子并进行互动。

社区内容不限于二手交易，也可以用于校园生活、学习交流等场景。

主要功能包括：

* 帖子发布
* 帖子浏览
* 帖子评论
* 社区互动
* 内容管理

## 6. AI 商品图片分析

项目接入 Qwen-VL-Max，对用户上传的商品图片进行视觉分析。

用户发布商品时，可以上传商品图片，视觉模型根据图片内容提取商品相关信息，为商品描述和价格填写提供辅助。

主要用于：

* 商品图片分析
* 商品信息识别
* 商品描述辅助生成
* 商品价格估算

这一部分主要解决用户发布商品时需要手动填写大量商品信息的问题。

## 7. AI 商品描述生成

项目接入 DeepSeek API，用于商品文本内容生成和补充。

用户填写商品基本信息后，可以让 AI 根据已有内容生成或补充商品描述。

例如用户只填写：

```text
商品：二手 iPad
型号：iPad Air
成色：九成新
价格：1500
```

AI 可以根据已有信息补充更加完整的商品描述，用户可以根据实际情况进行修改后再发布。

## 8. AI 对话

项目使用 LangChain4j 构建 AI 对话能力。

AI 对话并不是单独的聊天功能，而是与平台业务进行结合。

通过 LangChain4j 的 AI Service 定义对话服务，并将部分业务能力封装成 Tool，让模型在需要时调用后端提供的业务方法。

例如用户输入：

```text
帮我找一下 500 元以内的二手平板
```

系统需要先理解用户的查询条件，然后调用商品查询相关 Tool，后端根据价格、商品类型等条件查询数据库，最后将查询结果交给模型整理后返回。

这样 AI 获取的是平台实际商品数据，而不是仅根据模型自身知识进行回答。

## 9. Tool Calling

项目中将部分业务功能封装成 AI Tool，例如商品查询和业务数据查询。

Tool 本身负责具体业务处理，AI 负责根据用户问题决定是否需要调用对应工具。

以商品查询为例：

```text
用户输入自然语言查询条件

AI Service 接收用户问题

模型判断需要查询商品

调用商品查询 Tool

Tool 调用后端商品查询逻辑

数据库返回商品数据

AI 整理查询结果

返回用户
```

这种方式将 AI 对话和原有 Java 后端业务接口结合起来，使自然语言可以参与实际业务查询。

## 10. RAG 知识检索

项目在 AI 对话基础上加入 RAG，用于结合平台业务知识回答问题。

用户提出问题后，系统首先从知识库中检索与问题相关的内容，再将检索结果提供给模型作为上下文。

主要用于：

* 平台业务规则查询
* 商品相关知识查询
* 平台使用说明
* 商品推荐辅助
* 业务知识问答

RAG 主要解决模型本身不了解项目业务规则的问题，使回答能够结合项目中的实际知识内容。

## 11. AI 商品查询

平台除了传统关键词搜索外，还支持通过自然语言描述商品需求。

例如：

```text
我想找一个适合考研使用的二手平板，预算 1000 元左右
```

AI 可以从用户输入中提取商品类型、价格范围和使用场景等条件，再调用商品查询能力获取符合条件的商品。

后端实际查询数据库中的商品数据，AI 主要负责理解用户需求和整理查询结果。

## 12. 商品推荐

平台可以根据用户的历史行为进行商品推荐。

推荐数据主要可以来自：

* 商品浏览记录
* 搜索记录
* 收藏记录
* 历史购买记录
* 商品分类
* 商品标签

推荐模块可以根据用户历史行为计算用户兴趣，并结合商品特征筛选相关商品。

AI 能力也可以参与推荐结果的解释和整理，例如根据用户当前的自然语言需求，对符合条件的商品进行进一步筛选和说明。

## 13. 个人中心

个人中心用于管理用户自己的账户和交易信息。

主要包括：

* 个人资料
* 我的商品
* 我的订单
* 我的收藏
* 浏览记录
* 收货地址
* 账户余额
* 消息管理

平台对接支付宝沙箱，实现账户余额充值功能。

第三方支付相关代码对请求参数、响应结果和异常情况进行了统一处理。

## 14. 阿里云 OSS

商品图片及其他文件使用阿里云 OSS 进行对象存储。

文件上传后，后端获取 OSS 对象地址并保存到对应业务数据中。

基本流程：

```text
客户端上传文件

Spring Boot 接收文件

调用 OSS 上传接口

获取文件访问地址

保存文件地址及业务信息
```

这样可以将文件存储和业务数据库分开，数据库主要保存文件与业务对象之间的关联关系。

## 15. Redis 缓存

项目使用 Redis 对部分高频访问数据进行缓存。

主要用于减少重复数据库查询，提高高频访问场景下的数据读取效率。

缓存主要围绕商品及相关业务数据使用，具体缓存策略根据业务访问情况进行处理。

```text

    |
    | 接收请求、参数校验
    |

    |
```

# AI 模块结构

AI 相关功能主要基于 LangChain4j 实现。

```text
AI Service
    |
    +-- 商品查询 Tool
    |
    +-- 业务数据 Tool
    |
    +-- RAG 检索
    |
    +-- DeepSeek API
    |
    +-- Qwen-VL-Max
```

其中：

**AI Service**

负责定义 AI 对话服务以及模型调用。

**Tool**

将 Java 后端中的部分业务能力提供给模型调用。

**RAG**

负责从业务知识库中检索相关内容，为模型提供额外上下文。

**DeepSeek API**

主要用于文本对话和文本生成。

**Qwen-VL-Max**

主要用于商品图片分析。

# 开发内容

本人主要负责项目后端及 AI 相关功能开发，包括：

1. 使用 Spring Boot、MyBatis-Plus 完成用户、商品、订单、评论等核心业务模块开发。

2. 设计商品发布、商品状态管理、购买及订单状态流转等业务逻辑，并使用事务保证相关数据的一致性。

3. 使用 Sa-Token 实现用户登录认证和接口权限控制，对商品、订单、评论及个人数据进行业务权限校验。

4. 使用 WebSocket 实现买卖双方实时私信，处理用户连接、身份绑定及消息路由。

5. 使用 Redis 缓存部分高频访问的商品及业务数据，减少重复数据库查询。

6. 使用 LangChain4j 构建 AI 对话服务，通过 AI Service 和 Tool Calling 将商品查询等后端业务能力提供给 AI 调用。

7. 在 AI 对话中加入 RAG，用于检索平台业务知识并辅助模型生成回答。

8. 对接 DeepSeek API 和 Qwen-VL-Max，实现商品描述生成、图片分析及商品价格估算等功能。

9. 对接阿里云 OSS，实现商品图片及文件上传和对象存储。

10. 对接支付宝沙箱，实现账户余额充值相关功能，并处理第三方接口参数、响应和异常情况。
